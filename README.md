### 🚀 Featured Project — AutoDeliv

**Autonomous delivery robot** built end-to-end as a Final Year Project, now evolving into a startup.

- 🧠 **Compute:** Raspberry Pi 5 (ROS2 Jazzy) as main controller
- 🔌 **Microcontrollers:** ESP32-S3 (micro-ROS, CAN bus), ESP32-C3 dedicated to LiDAR acquisition
- 🗺️ **Navigation:** SLAM & Nav2, sensor fusion (IMU, GPS, LiDAR, TOF)
- 🔧 **Hardware:** 4 custom PCBs designed in EasyEDA Pro, manufactured at JLCPCB
- 🏗️ **Mechanical:** Chassis modeled in Fusion 360, two functional prototypes built
